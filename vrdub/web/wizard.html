设置步骤
向导不动 Windows 声音设置 它只把设备选择和 key 写进 config.json；麦克风、扬声器仍在系统里自己管。
01

选择麦克风

VRDUB 只采这一路输入。选错设备，对方听到的就是你的耳机漏音。

必填
输入电平−18 dB
−60−40−200 dB
驱动WASAPI 共享
采样48 000 Hz
通道单声道
缓冲10 ms
输入增益0 dB
!

现在说一句「测试一二三」。绿条应该在 −24 ~ −6 dB 之间来回跳；一直贴着左边不动，多半是选错设备，或者系统里被静音了。

02

选择输出设备

合成出来的声音写进虚拟声卡，VRChat 再从虚拟声卡把它当成麦克风取走。

推荐 CABLE Input

VRChat 里的麦克风要选 CABLE Output。改完在 VRChat 设置里点一次「刷新麦克风列表」，否则它还在用旧的默认设备，对方什么都听不到。

03

填 API key

云端识别、翻译、定稿精修共用这一把 key。先跳过也行，本地模型照样跑。

可跳过

不填会怎样 本地 ASR + 本地翻译

!

在服务商后台点 Copy，回到这里 Ctrl+V。前后空格和误带的 Bearer 前缀会被自动清掉；共用一台机器时，退出前记得把 key 删干净。

04

说一句试试听

点「试听」让 VRDUB 合成一句日语，确认声音真的进了虚拟声卡。

听不到声音？先看 Windows 音量合成器里 VRDUB 有没有电平，再确认 VRChat 麦克风选的是 CABLE Output。两步都对还是没有，就回第 ② 步换个输出设备。
