第 2 步 · 共 4 步

选择对方听到的设备

VRDUB 把翻译后的声音送进一张虚拟声卡，VRChat 再把那张声卡当麦克风。默认选 CABLE Input 就好。

已识别到 VB-Audio Virtual Cable 译文从 CABLE Input 播出，在 VRChat 的麦克风里选 CABLE Output，对方听到的就是翻译后的你。
VRDUB 合成音→ CABLE Input→ CABLE Output→ VRChat 麦克风

想顺带用耳机听一份合成音？进控制台在「我的监听」里再选设备，这一步先把对方那一路定下。
