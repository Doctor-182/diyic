# 打包（把源码变成别人能双击的东西）

这条流水线就是「容器化」的部分：**PyInstaller onedir 出程序目录 → 复制模型 → Inno Setup 出安装包**。产物不含任何密钥。

## 一键（你要的入口）

```bat
scripts\打包.bat
```

等价于依次跑：

```bat
py -3.12 tools\build_exe.py         :: PyInstaller onedir + 复制模型 + 冒烟自检
py -3.12 tools\build_installer.py   :: Inno Setup 编译安装包
```

## 文件在哪（全部在仓库里，可直接看）

| 文件 | 干什么 |
| --- | --- |
| `scripts/打包.bat` | 一键入口：`call scripts\_env.bat` 拿解释器 → 依次调下面两个脚本 |
| `tools/build_exe.py` | PyInstaller onedir 打包。`HIDDEN` 里点名四个 `--child` 子程序模块（hud/danmaku/ocr_overlay/region_picker），漏了子窗口会 `ModuleNotFoundError`；`MODEL_FILES` 决定哪 8 个模型文件进包（必需 252 MB，`anime-whisper` 732 MB 不进）；带 `--version-file` 生成 Windows 版本资源；末尾跑冒烟（独立 `VRDUB_HOME` + 端口 8912）。**默认不带 GGUF 三档**：加 `--with-gguf` 才会把 `transcribe_cpp` 运行库（1.0 GB，进 `_internal`）与 `models/asr/*.gguf`（3.1 GB）塞进包，安装包会从 264 MB 涨到 1.5 GB 以上 |
| `tools/build_installer.py` | 调 `ISCC.exe`，把 `/DAppVer` `/DAppVerFull` `/DProjRoot` 传进去 |
| `packaging/vrdub.iss` | Inno Setup 脚本：`{autopf}\VRDub`、`PrivilegesRequired=lowest`（可覆盖为管理员）、中文安装界面、开始菜单 + 可选桌面图标、卸载时询问是否连用户数据一起删 |
| `packaging/entry.py` | PyInstaller 的入口壳（`from vrdub.app import main`） |
| `packaging/vrdub.ico` | 图标，`tools/make_icon.py` 生成（PIL 画，7 个尺寸） |
| `packaging/lang/ChineseSimplified.isl` | Inno 官方简体中文语言包 |
| `packaging/lang/安装说明.txt` | 随包发给朋友的说明（会出现在安装目录） |
| `python -m vrdub.child`（`vrdub/child.py`） | 冻结后用 `VRDub.exe --child hud` 这种形式起子进程，源码跑则是 `pythonw -m vrdub.hud` |

产物：

| 路径 | 内容 | 体积（实测） |
| --- | --- | --- |
| `dist\exe\VRDub\` | `VRDub.exe` + `_internal\` + `models\` | 587.0 MB |
| `dist\installer\VRDub-<版本>-setup.exe` | 单文件安装包（lzma2/max，约 3.5 min） | 264.5 MB |

## 第一次在新机器上要装什么

| 依赖 | 说明 |
| --- | --- |
| Python 3.12 + 8 个库 | `requirements.txt` 已锁版本；本机做法是把轮子装进 `.pylibs\` 便携目录，`scripts\_env.bat` 会把它拼进 `PYTHONPATH` |
| PyInstaller | `pip install pyinstaller`（只在打包机上需要，不进最终产物） |
| Inno Setup 6.7.4 | 探测顺序：环境变量 `VRDUB_ISCC` → PATH 里的 `iscc` → `%ProgramFiles(x86)%\Inno Setup 6` → `%ProgramFiles%` → `%LOCALAPPDATA%\Programs`（本机另有一条便携目录兜底） |

## 冒烟（打完必做，3 分钟）

```powershell
$env:VRDUB_HOME = "$env:TEMP\vrdub-smoke"
$env:VRDUB_PORT = "8912"
Start-Process "dist\exe\VRDub\VRDub.exe"
Start-Sleep 18
Invoke-RestMethod http://127.0.0.1:8912/api/state | Select-Object ver,pid,frozen
```

看三件事：`frozen=True`、`hud/danmaku/overlay` 三个 `alive=true`、日志里 `SenseVoice 载入 … ms`。

## 密钥与用户数据（为什么安装包里没有 key）

- 打包脚本只复制 `vrdub/` 里的代码与静态页、`models/` 里那 8 个权重文件，**白名单式**，不扫工作区；`.env.local`、`data/settings.json`、`out/` 永远进不去。
- 用户的 key 存在 `%LOCALAPPDATA%\VRDub\config\.env.local`，由控制台「密钥」卡写入；安装包只带 `.env.example` 形状说明。
- 卸装默认保留用户目录（`%LOCALAPPDATA%\VRDub`），重装不用重填 key。
