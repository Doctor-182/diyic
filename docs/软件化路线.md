# 软件化路线（2026-11-25 定稿）

> 背景：引擎已达标（延迟、音色、三条链都跑通了），但外壳还是「能跑的研究原型」。
> 目标：别人的机器上双击就能用、坏了能定位、升级不炸。
> 本文是施工单，不解释原理。演进过程中的实测数据写进各节末尾。

## 0. 现状判词

引擎合格，外壳基本不存在。

| 项 | 实测 | 判定 |
|---|---|---|
| 代码 | `vrdub/` 1.6 MB / 66 文件 | 干净，不动 |
| 运行依赖 | `.pylibs` 518 MB、`_pylibs` 274 MB、`_pylibs_ct2_4.5.0` 121 MB、`_pylibs_ct2_4.6.1` 118 MB、`_pylibs_cuda` 1.95 GB | 无锁版本，靠解压目录 |
| 模型 | `models/` 1.04 GB | 与代码同目录 |
| 测试产物 | `out/` 362 MB / 5929 文件，顶层 97 项 | 日志/录音/截图/报告混一起 |
| 分发物 | `dist/` 源码 zip 0.4 MB + 模型 zip 161 MB | 「解压代码包再把模型覆盖进去」= 发资料 |
| 启动 | `run.bat` 写死了开发机的 dsh 运行时绝对路径，兜底还指向另一个私有目录 | 换机器起不来 |
| 配置 | `data/settings.json` 在程序目录 | 装 Program Files 写不进 |
| 日志 | `open(..., "ab")` 无限追加 | 无轮转（已修，见 §3） |
| 安装/卸载/托盘/向导 | 全无 | — |
| 垃圾 | 根目录 `%SystemDrive%\ProgramData`（打包路径没展开的残留） | 删 |

## 1. 六层缺口与做法

### 第 1 层 · 干净机器能不能跑
- PyInstaller `onedir` 冻结（PySide6 / onnxruntime / numpy / opencv / pyaudiowpatch / rapidocr）。
- `requirements.txt` 全 `>=` → 生成 `requirements.lock`（精确版本）。
- `run.bat` 降级为「开发/源码运行」，正式入口是 exe。
- 验收：一台没装过 Python 的机器，双击安装包 → 双击桌面图标 → 页面上线。

### 第 2 层 · 数据写哪、日志写哪
- 用户数据搬到 `%LOCALAPPDATA%\VRDub\`：
  - `config/settings.json`（首次启动从 `data/settings.json` 迁移，旧文件留 `.bak`）
  - `logs/`（err / hud / overlay / danmaku / tray / backend）
  - `cache/`（截图、临时 wav、OCR 裁图）
  - `recordings/`（`out/clips`、`out/corpus` 这类语料）
- 程序目录只读：`models/` 与代码可为只读。
- 日志 8 MB × 5 轮转（已落 §3 的基础版：8 MB × 1）。
- 验收：把整个程序目录设为只读，功能全通。

### 第 3 层 · 版本与身份
- `vrdub/version.py`：`APP_ID/APP_NAME/VERSION/CHANNEL/BUILD` + `short()/full()/frozen()`。
- 暴露面：页面关于区、`/api/health`、`/api/state`、启动日志首行、exe 版本资源、安装包版本。
- 发版流程：抬 `VERSION` → 打包脚本写 `BUILD` → 安装包读同一个常量。

### 第 4 层 · 运行时可靠性
- 单实例：`out/vrdub.lock` 文件锁（已有，达标）。
- 托盘：`vrdub/tray.py`（PySide6）→ 图标状态（运行/静音/异常）、菜单（打开控制台/静音/重载配置/看日志/退出）。
- 关窗 = 最小化到托盘；「退出」必须走 `/api/quit` 统一清理（子进程 hud/danmaku/ocr_overlay）。
- 崩溃兜底：顶层 `sys.excepthook` + `threading.excepthook` → 写 `logs/crash-时间.log` + 弹对话框（看日志 / 重启 / 退出）。

### 第 5 层 · 安装、卸载、升级
- Inno Setup 单文件安装器：开始菜单 + 桌面快捷方式（可选）+ 开机自启（可选）+ 卸载器。
- 模型**不进安装包**（1 GB）：首启动下载器（带 sha256 校验、断点续传）或独立的「模型包」勾选安装。
- 更新：`/api/version` 对比远端 `latest.json` → 提示（不静默更新）。
- 卸载：询问是否保留 `%LOCALAPPDATA%\VRDub\config`。

### 第 6 层 · 第一次打开
- 4 步向导：选麦克风（带电平条）→ 选输出设备（CABLE Input 默认）→ 填 key（贴 `.env.local` 也行）→ 说一句试听。
- 首屏红条：缺 key / 缺模型 / 设备选错 / 端口被占。
- 自检页：把已有 `run_selftest()` 接到 UI，输出可复制的报告。

## 2. 施工顺序

| 档 | 内容 | 风险 | 预估 |
|---|---|---|---|
| **P0** | 路径外移（config/logs/cache/recordings）+ 托盘 + 崩溃兜底 | 低（不动引擎） | 半天 · **路径外移已完成，托盘/崩溃兜底未做** |
| **P1** | PyInstaller onedir + Inno Setup 安装包 + 卸载/快捷方式/自启 | 中（打包坑多） | 一天 · **已完成（自启未做）** |
| **P2** | 首运行向导 + 自检页 + 更新检查 + 目录大扫除 | 低 | 一天 |

判断：**先 P0 再打包**。反过来等于把还要改的东西冻进 exe，每改一次重打包一次。

## 3. 已落地（按时间倒序）

### P1 打包与安装包（2026-11-25 完成）
- `vrdub/child.py`：子进程统一调度。源码模式 = `pythonw.exe + 脚本`；冻结模式 = `VRDub.exe --child <hud|danmaku|ocr_overlay|region_picker>`，进来跑完那一个子程序就退出。四个子模块在 `tools/build_exe.py` 的 `HIDDEN` 里显式点名（动态导入，PyInstaller 静态分析看不到）。
- `tools/build_exe.py`：onedir + windowed + 版本资源（`version.py` 生成 VSVersionInfo）+ 图标 + `--collect-all rapidocr_onnxruntime`；只复制 8 个必需权重（252.7 MB），anime-whisper 732 MB 不进包。产物 587 MB，耗时 83 s。
- `packaging/vrdub.iss` + `tools/build_installer.py`：Inno Setup 6.7.4，lzma2/max，中文向导，开始菜单 + 可选桌面图标，卸载时问是否删用户目录。**安装包 264.5 MB，装完 591 MB，压缩 213 s**。
- 密钥面板（`api_env` + 网页「密钥」卡）：安装版唯一必须手填的东西；写 `%LOCALAPPDATA%\VRDub\config\.env.local`，保存后立刻打一次 `/compatible-mode/v1/chat/completions` 自检并回显 HTTP 码。实测：假 key → `probe=fail`，真 key → `probe=ok`，无需重启进程。
- 打包版实测：静默装到临时目录 → 启动 20 s 内 `/api/health` ok、`hud/danmaku/overlay` 三个浮窗全 alive、SenseVoice 载入 3431 ms；无 key 时报 HTTP 401 并降级本地，行为与源码模式一致。

### P0 路径外移（2026-11-25 完成）
- 新增 `vrdub/paths.py`：程序目录（只读可）与用户目录（`%LOCALAPPDATA%\VRDub\config,logs,cache,out,recordings}`）分离；`VRDUB_HOME` / `VRDUB_ROOT` 可覆盖（多开、便携模式、调试用）。
- `cfg.py` / `util.py` / `corpus.py` / `bench.py` / `ocr.py` / `server.py` 全部改走 `paths`；老 `data/settings.json` 与 `.env.local` 首次启动自动复制到用户目录（`Cfg.migrated` 会报出来）。
- 依赖与模型路径不再出现任何本机绝对路径：`_ocr_engine.py` 的 det/ch/ja 模型改成「先找程序目录 `models/ocr`，再找 `.pylibs`」，并把 det（4.7 MB）与 ch rec（10.4 MB）复制进 `models/ocr`，换机器不用再从依赖包里翻。
- `scripts/_env.bat`：解释器探测链 `VRDUB_PYTHON` → `.runtime\python.exe` → `py -3.12` → `py -3` → `python`；`PYTHONPATH` 只拼 `.pylibs;程序目录`，删掉指向开发机私有目录的兜底。`run.bat` / 检查环境 / 评测 / 延迟报表 全部改走它。
- 密钥纪律：`tools/pack.py` 不再打 `.env.local`（只带 `.env.example`）；端点可由 `DASHSCOPE_TOKENPLAN_BASE` / `DASHSCOPE_PAYG_BASE` 覆盖（`cfg._host_of` 认 URL 或域名）。
- git 仓库建立（`main`），忽略权重/环境/产物/密钥，提交量 1.5 MB 量级；`tools/` 与 `tools/dev/` 分层，真值表进 `tests/`。
