选择麦克风

选中你平时说话用的麦克风。正常说话时，电平应越过黄色门限。

输入电平模拟信号已暂停
−60−40−200 dB

预览中的设备为示例，电平由动画模拟。

选择输出设备

把合成语音送进虚拟音频线，让 VRChat 里的其他玩家听到译音。

在 VRChat 中选择 CABLE Output 作为麦克风

VRDUB 输出CABLE Input→CABLE OutputVRChat 麦克风

如果只想在本机试听，可以选择耳机或扬声器。
